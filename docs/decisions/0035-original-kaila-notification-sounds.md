# ADR-0035: Original KAILA notification and call sounds

- Status: Accepted
- Date: 2026-08-02

## Context

KAILA previously used Android/system default notification and ringtone sounds. The design system asks for subtle, event-specific audio for matches, offers, acceptance, messages, arrival, and calls.

## Decision

Ship original, procedurally generated KAILA tones (no third-party samples):

| Event | Asset | Android channel / notes |
| --- | --- | --- |
| Job match | `kaila_job_match` | `kaila_match_v1` |
| Hired / offer selected | `kaila_job_hired` | `kaila_hired_v1` |
| Chat message received | `kaila_message` | `kaila_messages_v1` |
| Message sent (in-app) | `kaila_message_sent` | — |
| First offer | `kaila_offer` | `kaila_offers_v1` |
| Counteroffer / revised terms | `kaila_counter_offer` | `kaila_counters_v1` |
| Peer typing (in-app) | `kaila_typing` | — |
| Message reaction (in-app) | `kaila_react` | — |
| Job updates | `kaila_job_update` | `kaila_updates_v1` |
| Travel / arrival | `kaila_travel` | `kaila_travel_v1` |
| Support / dispute | `kaila_support` | `kaila_support_v1` |
| Incoming call | `kaila_call_ring` | `kaila_calls_v3` |
| Outgoing ringback (in-app) | `kaila_call_ringback` | — |
| Call answered (in-app) | `kaila_call_answered` | — |
| Call ended / declined (in-app) | `kaila_call_ended` | — |
| Call failed (in-app) | `kaila_call_failed` | — |

Assets live in `apps/web/public/sounds/` and `apps/mobile/android/app/src/main/res/raw/`, regenerated by `scripts/generate-kaila-sounds.py`.

FCM maps `eventType` + route `type` to the channel and raw sound name. Web/desktop plays the matching WAV for durable `notification.created` feedback.

In-app UI cues (typing, react, message sent, ringback, answered/ended/failed) play in the WebView—including Capacitor—and are not push notification sounds. Incoming ringtone on native Android remains owned by `IncomingCallActivity` / the calls channel.

New channel IDs are required because Android channel sounds are immutable after first creation.

## Consequences

- Existing installs keep legacy channels; new pushes use the branded `*_v1` / `kaila_calls_v3` channels.
- Quiet hours still route to `kaila_silent`.
- Users can still override per-channel sounds in system settings.
- Counteroffers use a separate channel from first offers so each can keep a distinct sound.
