# ADR 0005: Adopt the blue bull mascot brand identity

## Status

Accepted — 2026-08-22

## Context

The approved product artwork replaces the earlier map-pin-and-tools mark with a rounded KAILA wordmark, a friendly blue bull mascot, a horizontal mascot lockup, and a mascot app icon. The existing primary blue and accent cyan tokens remain compatible with the new artwork.

## Decision

- Use the supplied blue/cyan wordmark as the canonical KAILA wordmark.
- Use the supplied mascot artwork for app icons and prominent identity surfaces.
- Generate browser, PWA, Apple, and Android launcher derivatives from the square mascot master.
- Preserve the canonical wordmark colors on light surfaces. Use the white/cyan accessibility derivative on dark and gradient surfaces.
- Keep technical identifiers such as package namespaces, domains, realtime channels, environment variables, and Android application IDs unchanged.
- Keep administrative tooling structurally and visually separate while using the same corporate identity assets.

## Consequences

The visible product identity now matches the approved mascot artwork across web, admin, PWA, and Android entry points. The design system's former map-pin logo guidance is superseded, while its palette, accessibility, spacing, motion, and architecture requirements remain unchanged.
