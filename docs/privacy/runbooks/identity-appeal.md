# Identity verification — appeal runbook

| Field | Value |
| --- | --- |

| Updated | 2026-09-11 |

1. User requests appeal from `/identity-verification` after rejection.
2. System records `appeal_requested_at` and notifies admins.
3. **Independent reviewer required.** In a one-person operation, do not decide your own appeal. Options: retain a temporary trained reviewer, or leave the case escalated/paused with the user informed of delay.
4. Record outcome and reason code; notify the user.
5. Retention clock follows rejected/approved schedules in the compliance pack.
